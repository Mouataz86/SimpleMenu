# 🎮 SimpleMenu for GTA V [Single Player] – v1.2

**SimpleMenu** is a clean, modular, and open-source GTA V mod menu for Story Mode. Built using **SHVDN3** and **LemonUI v2.2**, it offers a powerful set of gameplay tools — from player enhancements to teleportation, vehicle control, and visual tweaks.

---

## ✅ What’s New in v1.2

### ✨ New Submenus & Features

#### 🚗 Vehicle Functions *(New submenu)*
- Toggle Engine On/Off
- Lock/Unlock Doors
- Open/Close All Doors (including trunk/hood)
- Always Seatbelt (prevent crash ejection)

#### 🚓 Wanted Level Upgrades
- Clear Wanted Level
- Never Wanted Toggle
- Police Ignore Player
- Disable Civilian Reports
- Disable Dispatch Services (no backup spawns)

#### 🔫 Weapon Upgrades
- Super Accuracy (removes bullet spread)
- No Recoil (removes gun kick)

#### 🧪 Custom Weapons *(Experimental)*
- Vehicle Gun (shoot vehicles)
- Ped Gun (shoot peds)
- Teleport Gun (teleports you to where you shoot)

> ℹ️ Custom weapons are currently placeholder (show notifications only).

#### 🧍 Player Model & Outfit Tools
- Change Player Model (Freemode, Story, Peds from JSON)
- Customize Clothing & Props (drawables and textures)
- Reset to Default Character
- Random Outfit Generator

#### 📍 Important Teleports *(New submenu)*
- Gun Shops, Clothing Stores, Hospitals, Police Stations
- Loads from `teleports.json` for easy customization

#### 🎮 Stat Maxing *(Story Characters Only)*
- Max All Player Stats: stamina, strength, driving, flying, shooting, stealth, lung capacity

---

## ⚙️ Enhancements

- Improved **Teleport to Waypoint**: now works properly while in vehicles

## 💾 INI Hotkey Support

Easily configure hotkeys in `SimpleMenu.ini`:

[Hotkeys]
ToggleGodMode = NumPad1
GiveAllWeapons = NumPad2
FreezeAmmo = NumPad3
NeverWanted = NumPad4
ToggleSpeedometer = NumPad5
TeleportToWaypoint = NumPad6
ToggleFastRun = NumPad7
ToggleSuperJump = NumPad8

## 🧪 Known Bugs & Limitations

- Some features like "Max Stats" may need game reload to fully apply ( Aborted )
- Camera effects (Cinematic Bars, Shake) are partially limited by LemonUI & SHVDN3
- Kill Enemies may not affect animals or modded NPCs
- Experimental Custom Weapons are not fully implemented yet
