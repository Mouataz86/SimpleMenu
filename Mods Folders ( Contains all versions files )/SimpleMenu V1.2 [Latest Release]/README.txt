HOW TO INSTALL
--------------------------
1- Copy all the files into your scripts folder ( Create it if it doesn't exist )
2- Enjoy

Note: the json files won't work if you placed the files outside the scripts folder!




SimpleMenu v1.2 – The Ultimate SP Trainer
-----------------------------------------

Author      : Mouataz86
Release Date: July 2025
Target Game : Grand Theft Auto V (Story Mode)
Framework   : SHVDN3 + LemonUI 2.2
License     : MIT
Type        : Open Source Trainer

DESCRIPTION
-----------
SimpleMenu is a clean, fast, and user-friendly mod menu for GTA V Story Mode. 
It gives you full control over the game world with powerful options across Player, Vehicles, Weapons, Teleports, and more. 
Built entirely with SHVDN3 and LemonUI 2.2, it ensures modern, stable, and responsive performance.

WHAT’S NEW IN VERSION 1.2
-------------------------
PLAYER SETTINGS
- Full player model changer with support for peds, freemode, and main characters
- Complete clothing customization: drawables, textures, props (hats, glasses, etc.)
- Random outfit generator
- Reset to default outfit option
- Max all player stats (stamina, strength, driving, stealth, etc.) – story mode only - Commented Not Working

VEHICLE SETTINGS
- New submenu: Vehicle Functions
  - Toggle engine on/off
  - Lock/unlock all doors
  - Open and close all doors including hood/trunk
  - Always Seatbelt (prevent crash ejection)
- Improved teleport to waypoint (works correctly when in vehicle)

WANTED SETTINGS
- Clear Wanted Level
- Never Wanted Toggle (suppresses stars and chase triggers)
- Police Ignore Player Toggle
- Disable Dispatch Services (no reinforcements)
- Disable Civilian Reports (nobody calls the cops)

WEAPON SETTINGS
- Super Accuracy (no bullet spread)
- No Recoil (disables weapon shake)
- Custom Weapons Submenu (EXPERIMENTAL)
  - Vehicle Gun: shoot vehicles
  - Ped Gun: shoot peds
  - Teleport Gun: teleport to impact location
  (Currently these only show notifications)

TELEPORT OPTIONS
- New submenu: Important Teleports
  - Gun shops, Clothing stores, Hospitals, Police Stations
  - Loads from a customizable data file
  - Player spawns outside each building for convenience

ADDITIONAL FEATURES
- .INI hotkey support for God Mode, Waypoint Teleport, etc.
- Menu remembers the last submenu used and reopens it
- Fully nested LemonUI menus with checkbox, list, and submenu integration
- Notifications for feature toggles and activations

KNOWN ISSUES / LIMITATIONS
--------------------------
- Camera shake and cinematic bars not implemented (not supported by LemonUI SHVDN3)
- Kill All Enemies may not affect animals or modded peds
- Custom weapons (Teleport/Ped/Vehicle Gun) currently under development
- Max Stats may require reloading or save to reflect changes in-game UI
